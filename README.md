# 美团POS自动化工具

这个工具用于自动化登录美团POS系统，并从营业概览中提取各仓库销售数据。适用于需要批量获取美团POS销售数据的商家。

## 功能特点

- 自动登录美团POS系统（使用手机号+验证码）
- 自动/手动处理滑块验证码
- 自动选择指定机构（默认"叁石哥丰都麻辣鸡"）
- 自动隐藏各类引导弹窗
- 自动导航至报表中心和营业概览页面
- 批量提取所有仓库的销售数据并保存结果
- 监控API响应，提取并展示仓库信息

## 环境要求

- Python 3.6+
- Chrome浏览器
- Chrome WebDriver
- 以下Python库：
  - selenium
  - selenium-wire
  - tqdm

## 安装

```bash
pip install selenium selenium-wire tqdm
```

## 使用方法

1. 配置常量（CONFIG字典中）：
   - 修改手机号（PHONE_NUMBER）
   - 修改目标机构名称（TARGET_ORG）

2. 运行脚本：

```bash
python meituan.py
```

3. 交互提示：
   - 需手动输入短信验证码
   - 如选择手动模式，需手动完成滑块验证

## 配置选项

脚本顶部提供了两个主要配置选项：

```python
# 滑块验证模式: 0=自动, 1=手动
SLIDER_VERIFY_MODE = 0
# 是否监控API响应
MONITOR_API_RESPONSE = True
```

- `SLIDER_VERIFY_MODE`：设置为0启用自动模式，设置为1则需要手动完成滑块验证
- `MONITOR_API_RESPONSE`：开启后会监控并保存API响应数据
- 可在CONFIG字典中修改其他配置项

## 工作流程

1. 打开Chrome浏览器并导航至美团POS登录页面
2. 自动填入手机号码
3. 获取并输入短信验证码（需手动输入）
4. 处理滑块验证码（自动或手动模式）
5. 登录成功后自动选择指定机构
6. 自动导航到报表中心
7. 跳转到营业概览页面
8. 执行高级查询，批量获取所有仓库数据
9. 使用进度条显示处理进度
10. 将结果保存至`warehouse_results.json`文件

## 输出结果

脚本执行完成后，会生成`warehouse_results.json`文件，包含所有仓库的销售数据：
- 仓库名称
- 收入金额（元）
- 销售数量（笔数/车辆数）
- 平均销售额（元/笔）

## 注意事项

- 首次运行时可能需要手动处理滑块验证
- 确保网络稳定，避免登录超时
- 短信验证码仍需手动输入
- API监控功能依赖于SeleniumWire库
- 可能需要定期更新，以适应美团POS系统的变化
